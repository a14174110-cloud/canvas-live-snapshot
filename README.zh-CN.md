# Canvas Live Snapshot

> **保存此刻的 Canvas，归档当前视觉状态。**

Canvas Live Snapshot 面向复杂 Obsidian Canvas 的视觉归档。它直接捕获 Obsidian 当前已经渲染的节点、分组、计算样式和 SVG 连线路径，生成 HTML 快照，再通过浏览器打印为 PDF。

对于 Advanced Canvas 的 Straight、Squared、A* 等连线，插件复制当前生成的 SVG 路径，无需重新实现其路径算法。对于支持截图的网页节点，它尝试将 WebView 当前可见画面冻结为 PNG，留存截图时的页面内容及滚动位置所对应的视图。

快照自动保存到 Downloads 并打开，让研究画布、流程图和评审材料更方便地进入归档流程。**所见即所得是设计目标，实际效果取决于节点渲染、网页截图支持和浏览器打印能力。**

## 核心思路：Live Render Snapshot

从 `.canvas` 数据构建输出，需要解释节点属性、重新处理布局与连线，并实现相关插件的视觉规则。本插件使用渲染完成后的 DOM、计算样式与 SVG 作为快照来源。

```text
Obsidian + Advanced Canvas / 当前主题
                  ↓
      已完成布局和路径计算的画布
                  ↓
    捕获节点 DOM、计算样式和 SVG
        ＋ 冻结可截图的 WebView
                  ↓
              HTML 快照
                  ↓
          浏览器打印 / 保存 PDF
```

这一路径的价值在于直接复用已经算好、已经显示的视觉结果。它以减少重新实现第三方渲染规则的需要为设计出发点；不能据此推断所有 Canvas 插件都已兼容。

## 对复杂画布有什么价值

- **连线保留实际路径。** 复制渲染后的 SVG，包括其中的路径与计算样式；Straight、Squared、A* 的最终走向无需再次计算。路径复制已实现，各种主题和边样式的最终打印效果仍需实测。
- **网页留存当前可见画面。** WebView 截图成功时，快照包含截图瞬间可见的内容、背景及滚动位置对应的视图。它不会保存完整网页、页面交互、视频过程或屏幕外内容；多个节点按顺序截图，也不是同一时刻的原子快照。
- **主题样式来自当前渲染。** `getComputedStyle()` 复制节点实际使用的颜色、边框、字体属性和透明度等。字体文件、伪元素、外部资源及特殊渲染层仍可能无法完整带走。
- **文字与路径保留结构。** 普通节点使用 HTML，连线使用 SVG，可截图网页等内容使用 PNG；无需把整张画布先压成一张位图，但不承诺所有 PDF 内容都可搜索或完全矢量化。
- **归档步骤更少。** 自动保存、自动打开，再由用户通过打印窗口确认 PDF。时间戳文件名和重名避让便于留存不同阶段的快照。

## 与其他导出方案相比，优势在哪里

核心优势是**复用当前渲染结果、冻结可截图网页、自动保存并打开**这三步组成的工作流程。下面根据项目公开文档比较定位，未进行同一画布的效果或性能实测，不代表本插件全面优于其他插件。

| 方案 | 已有能力与适合场景 | Canvas Live Snapshot 的侧重点 |
| --- | --- | --- |
| [Advanced Canvas](https://github.com/Developer-Mike/obsidian-advanced-canvas) | 已支持整张画布或选区的透明 PNG / SVG 导出，适合输出图片 | 补充 HTML 快照、网页画面冻结与浏览器打印流程；可配合它使用 |
| [Canvas HTML Exporter](https://community.obsidian.md/plugins/canvas-html-exporter) | 支持交互 HTML、搜索、缩放、折叠及已保存的 Advanced Canvas 属性，适合浏览和分享 | 从当前已渲染 DOM / SVG 制作快照，适合记录当下画面并打印；不提供同等交互浏览功能 |
| [Canvas to PDF](https://github.com/2d3dtreasures/obsidian-canvas-to-pdf) | 提供 PDF 与 HTML 导出，强调可搜索的矢量 PDF | 复用当前渲染连线路径，并自动打开 HTML 进行打印；需要直接 PDF 的用户应比较其专用导出能力 |

适合：需要把当前 Advanced Canvas 画面、已加载网页和布局留作汇报、评审或资料快照，并希望减少导出后操作的人。

如果你更需要交互式网页、完整导出未渲染节点、批量转换或直接生成 PDF，本插件当前不是这些需求的完整解决方案。复杂画布的实际保真度仍需验证。

## 安装

当前尚未上架社区插件目录。

手动安装：将发布包中的 `main.js`、`manifest.json` 和 `styles.css` 放入 `你的仓库/.obsidian/plugins/canvas-live-snapshot/`，重启 Obsidian，在「设置 → 第三方插件」中启用 **Canvas Live Snapshot**。使用自定义配置目录时，请相应替换 `.obsidian`。

## 使用步骤

1. 打开需要导出的 Canvas，结束节点文字编辑。
2. 缩放到能够看到全部节点，等待图片和网页加载完成。
3. 打开命令面板，执行「Canvas Live Snapshot: 导出当前 Canvas HTML 快照（用于打印 PDF）」，或点击左侧导出按钮。
4. 导出期间不要切换、滚动或缩放画布。
5. HTML 会自动保存到系统下载文件夹，并按系统的 HTML 默认打开方式启动。
6. 在打开的页面点击 **Print / Save PDF**，选择保存为 PDF。开启背景图形，关闭页眉页脚，检查预览后保存。

插件输出的是 HTML；PDF 由浏览器打印生成。超大画布可能超过浏览器纸张限制，不能保证任何尺寸都能输出为单页 PDF。

## 设置

- **输出目录**：显示系统下载文件夹路径，优先读取系统设置，无法读取时使用用户主目录下的 Downloads。
- **画布边距**：调整快照四周留白。

文件名包含画布名称和时间戳，遇到重名会自动加序号。不会修改原 Canvas。旧版保存在仓库中的输出目录设置会被忽略。

## 常见问题

**打开到了编辑器？** 将系统中 `.html` 文件的默认打开方式改为浏览器。

**提示保存成功但自动打开失败？** 按通知中的路径找到 HTML 并手动打开，已保存的文件不会丢失。

**节点缺失？** 本插件依赖已渲染的 DOM，无法捕获被虚拟化隐藏的节点。先缩放到全图并等待渲染完成。

**网页空白？** 等待网页加载后重试。网页截图失败会回退为 iframe；跨域、安全策略或站点限制可能导致 iframe 无法显示。

**PDF 被裁切或分成多页？** 检查打印预览和设置；画布过大时可进一步缩小画布缩放比例再导出。

## 兼容性与已知限制

仅支持桌面端。Advanced Canvas 为可选插件，本项目与其独立。当前界面为中文。

依赖 Obsidian 内部 Canvas DOM，版本或主题变更可能影响效果。导出保留当前缩放比例，字体、伪元素、分组补框和主题特效不能保证完全一致。未内嵌成功的资源保留原地址，离线或跨设备时可能缺失。

已通过语法与模拟 API 测试，尚未在真实 Obsidian 中验证视觉效果及 PDF 分页；最低兼容版本也需在正式提交前验证。

## 隐私与文件访问

无需付费或额外账号，无遥测、广告和专用导出服务器。插件会在仓库外的系统 Downloads 文件夹写入 HTML，并调用系统打开该文件。

导出时可能请求画布中已有的图片和背景资源地址。打开 HTML 时，未内嵌资源和回退 iframe 可能连接其原站点；这些站点可能需要登录。快照包含画布可见内容和网页截图，分享前请检查内容。
